# Respostas de exemplo da Shopee Affiliate Open API

Usadas pelos testes do parser (`parser.test.ts`).

**Atenção:** os arquivos marcados como `exemplo-*` foram montados a partir da documentação
parcial, não gravados da API real. Os nomes dos campos são suposições (veja os TODO em
`client.ts`). Quando rodar o comando de teste com a conta real e a opção `--gravar`,
as respostas reais são salvas como `real-*.json`. Copie-as para cá e ajuste os testes.

Os dados de produto aqui são fictícios.
